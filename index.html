Features

为「复制粘贴」重新设计体验

不只是历史记录——从呼出、捕获、整理到插入的每一步，都是一块会呼吸的液态玻璃。

全类型剪贴板历史

文字、图片、真实文件全捕获。单击复制、长按呼出菜单、置顶与标签整理，搜索关键词高亮直达。

悬浮窗秒呼秒贴

全局悬浮球一键展开，不抢占前台焦点；内容直接以 Ctrl+V 插入微信、Word 等任意应用，文件可拖出另存。

输入法剪贴板面板

安卓键盘内置历史面板：短语一键上屏、图片文件直插聊天、专属退格键随时改字，打字粘贴两不误。

大文件不设上限

图片与文件流式分块传输，64KB 到几百 MB 一视同仁；惰性下载、进度实时可见，断点续写不重复。

敏感内容自动守护

验证码、密钥、口令自动识别标记，隐私模式一键打码，揭示 8 秒后自动回码，分享截图不慌。

效率彩蛋合集

文本一键生成二维码、使用统计 Top5、其他应用分享直接入库、自动打标签、桌面快捷方式与通知栏快捷复制。

Cross-Device

三条通道，手机电脑互为剪贴板

同一份历史，双端实时流转。复制即同步，粘贴即拥有。

局域网 IP 直连 零配置

同一 Wi-Fi 下输入对方 IP 即连，桌面悬浮窗实时显示本机地址，一键复制配对。

IPv6 跨网直达 出公网

内置 TCP 可达性探测，公网 IPv6 打通后可跨校园网、跨城市直传；被运营商拦截时自动引导回退。

经典蓝牙 RFCOMM 无网可用

没有 Wi-Fi 也能配对互传：文本、图片、文件随行传输，512KB 大分块 + 256KB 收发缓冲，速度拉满。
